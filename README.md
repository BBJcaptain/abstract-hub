# Abstract Hub

A private reading library.

<!-- VERSION:START -->
**Version:** App `v1.8` · Library `2026v6`
<!-- VERSION:END -->

---

Abstract Hub is a personal, offline reader for summaries of books and reports.

**This repository is public. What it holds is not.** The library is encrypted
before it is published. Without the passphrase, the data file here is
indistinguishable from random noise. Decryption happens only in the browser, on
the reader's own device.

There is no server, no account, and no recovery route. That is deliberate: there
is nothing anywhere that could recover it.

## Installing

1. Open the site in Safari on iPhone or iPad.
2. Share → **Add to Home Screen**.
3. Launch it from the home screen and enter the passphrase.

It works offline after the first load.

## Reporting a security issue

If you believe you have found a vulnerability, please open an issue with
`SECURITY` in the title and no exploit detail, and I will follow up privately.
Please do not put anything sensitive in a public issue.
